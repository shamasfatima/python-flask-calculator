# 🧮 Python Flask Calculator

A simple web calculator built with Python, Flask, HTML, CSS, and JavaScript.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Square (x²)
- Remainder (%)
- Division-by-zero error handling
- Modern dark interface with neon-blue styling

## Technologies Used
- Python
- Flask
- HTML5
- CSS3
- JavaScript

## How to Run

1. Install Python.
2. Install Flask:

   `python -m pip install flask`

3. Download or clone this repository.
4. Open a terminal in the project folder.
5. Run:

   `python calculator.py`

6. Open `http://127.0.0.1:5000` in your browser.
